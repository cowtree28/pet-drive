## 6. 데모 APK — 지금 있는 것과 2차 PT까지 할 것

**지금 있는 것:** `submit/05_데모앱_펫드라이브.apk` (Gradle 프로젝트, Android Studio로 열 수 있음. release 빌드·코드 축소 14MB, 데모용 디버그 키 서명)
- Pleos Connect SDK: `ai.pleos.playground:Vehicle:2.3.2`(브레이크, 실내 온도, 에어컨, 기어), `NaviHelper:3.0.5`(목적지 경로, 휴게소 경유지, 경유지 도착), `TextToSpeech:3.3.1`·`SpeechToText:3.3.1`(기기 내, ko-KR), `FusedLocation:1.1.3`(위치 → 실제 바깥 기온). 속도는 Vehicle SDK에 없어 `CarPropertyManager`(PERF_VEHICLE_SPEED)
- 에뮬레이터는 그래픽을 `-gpu host`(Android Studio에서는 Graphics: Hardware)로 켜야 내비 지도를 그릴 때 꺼지지 않음
- **Pleos Connect 에뮬레이터 v2.1.0에서 실행 확인.** 녹화는 `design/video/app-run-pleos.mp4` (`tools/make_app_video.py <녹화> <ffmpeg> pleos`)
- 일반 기기에서는 자동으로 가상 주행 기록(60배속) 모드. Pleos에서도 "기록 재생" 버튼으로 같은 시나리오를 돌릴 수 있음

**Pleos 에뮬레이터에서 시연하는 법 (2차 PT)**
1. Android Studio SDK Manager → SDK Update Sites에 `https://nexus-playground.pleos.ai/repository/raw-releases/connect-avd/2.x/crp-sys-img.xml`(Mac은 `crp-arm64-sys-img.xml`) 추가 → API 34 Pleos Connect 이미지 설치 → Automotive AVD, Cold boot, RAM 4GB
2. `adb install -r -g build/apk/petdrive-demo.apk` (`-g`로 속도 권한까지 허용)
3. `adb forward tcp:8088 tcp:8088` 후 브라우저에서 `http://127.0.0.1:8088/` (Virtual Console)
4. (겨울이면 펫 지킴이의 "한여름 33℃" 칩으로 바깥 기온을 시연 값으로) 기어 D(내비에 강릉 경로 요청) → 속도 60 ↔ 20을 브레이크와 함께 반복 → 점수 상승, 음성 안내 → "콩이 힘들어해" → 위험(내비 경유지에 휴게소 추가) → 기어 P → 펫 지킴이 켜기 → 콘솔에서 A/C 끄기 → 위험 대응 → 도착 탭에서 컨디션 기록

**2차 PT까지 남은 것 (Android 담당)**
1. 펫 지킴이 온도 상승은 지금 데모 계산 → 실내 온도 신호만으로 판단하도록 정리
2. 실제 마이크가 있는 환경(노트북 에뮬레이터 창 모드)에서 STT 문장 인식 확인
3. 휴게소 좌표를 고정값 대신 경로 위 반려견 휴게소 목록에서 고르기
4. 팀 키로 release 서명
