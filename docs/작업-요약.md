# 작업 요약 (2026-11-15 새벽)

## 바뀐 것: 아이디어와 이름

- **핵심 기능을 "주행 중 멀미 케어"로 옮겼다.** 처음 핵심이던 펫 지킴이(정차 중 공조 유지)는 테슬라 Pet Mode, 리비안, 루시드, 현대·기아 펫 모드에 이미 있다. 반면 주행 중 반려견 멀미 조건을 재고 운전·휴식 경로까지 돕는 기능은 찾지 못했다. 펫 지킴이는 보강해서 유지했다.
- **앱 이름을 "펫 모드" → "펫 드라이브(가칭)"로 바꿨다.** 현대·기아 인포테인먼트에 같은 이름의 정차 중 기능이 있다(현대·기아 오너스 매뉴얼). 팀이 더 좋은 이름을 정해도 된다.
- **차량 제어 SDK(set 계열)는 공개가 확정되지 않아** 기본 단계(조회·내비·음성·위치)와 확장 단계(창문·공조·조명 제어)로 나눴다. 핵심 기능은 기본 단계만으로 동작한다.

## 검증한 방법

- 공모전 공식 홈페이지(심사 기준, 제출 방법, FAQ), 접수양식, Pleos 디자인 가이드와 SDK 문서, 팀의 SDK 정리 메모를 직접 읽고 반영했다.
- 통계는 원출처를 확인했다(KB 2021·2025, 한국관광공사 2022, 한국교통안전공단 2024, 한국도로공사 2025).
- 심사위원 관점 검토 2번, 디자인 검토 1번, 전체 일관성 검토 1번을 독립적으로 받고 지적 사항을 고쳤다.
- 화면과 영상은 렌더링한 이미지를 직접 보고 확인했다. DOCX는 Word로 열어 보지 못했고, python-docx로 구조(칸 8개, 그림 1개)만 확인했다.
